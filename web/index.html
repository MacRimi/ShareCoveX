ACCESO AL PANEL

Administradores

Debe existir al menos un administrador.

    Estas cuentas permiten administrar todo ShareCoveX. Las contrasenas se guardan como hashes derivados en /config/admins.json, nunca en texto plano.

    IDENTIDAD EN RED

    Nombre y descubrimiento

    Este nombre aparece al explorar servidores SMB en Finder. No cambia el hostname del LXC ni renombra las carpetas compartidas.

    Anunciar este servidor por Bonjour en la red local

    Publica SMB por mDNS (UDP 5353). Finder decide el icono y puede mostrar uno generico aunque reciba el modelo de almacenamiento. En Docker con red bridge, el anuncio puede no salir a la LAN.

    Comprobando
    SERVICIO SMB

    Compatibilidad de protocolo

    Samba negocia automaticamente la version con cada cliente. Limita el rango solo si necesitas compatibilidad concreta; SMB1 no se ofrece por seguridad.

    ACCESO SMB

    Usuarios Samba

    Aun no hay usuarios SMB. Crealos aqui y asignales recursos desde Recursos > Editar.

      Cada usuario muestra sus recursos y permisos. Pulsa un recurso para editarlos; cambia la clave o elimina el usuario aqui. Las contrasenas no se guardan en el panel: Samba conserva sus hashes en /config.

      ARCHIVOS COMPARTIDOS

      Identidad y permisos

      El modo colaborativo hace que SMB y NFS creen contenido con una identidad compatible para que los usuarios autorizados puedan editar los archivos de los demas.

      Activar modo colaborativo

      Valor recomendado: 1000:1000. ShareCoveX no cambia automaticamente el propietario de las carpetas montadas. Consulta su compatibilidad en Recursos compartidos.

      SERVICIO NFS

      NFSv3 activo

      Este servidor usa NFSv3 porque se ejecuta en un LXC sin privilegios. Para utilizar NFSv4 se necesita un LXC privilegiado.

      SERVICIO NFS

      Protocolos NFS

      Selecciona NFSv3, NFSv4 o ambos. NFSv4 necesita NFS-Ganesha y acceso real a file handles.

      Protocolos habilitados
      NFSv3
      NFSv4

      COPIAS DE MAC

      Time Machine

      Define el tamano que Samba comunica a macOS para que Time Machine gestione y recicle sus copias. Usa una carpeta exclusiva. Una cuota estricta debe configurarse tambien en el dataset o volumen del host.

      Limitar el tamano de los destinos Time Machine

      En Recursos, activa SMB y escritura, selecciona al menos un usuario Samba y desactiva NFS e invitados para esa carpeta.

      CAMBIO DE PROTOCOLO

      Configuracion NFS anterior

      Esta instalacion tenia recursos NFSv4. No se han convertido en silencio: el backend anterior no funciona con estos montajes en el LXC sin privilegios. NFSv3 cambia la ruta exportada a /shares/... y no ofrece bloqueo NLM ni Kerberos.
